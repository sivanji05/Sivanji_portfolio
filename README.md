# Sivanji Portfolio

A single-page personal portfolio website for Nooli Sivanji, showcasing AI, full-stack development, and freelance experience.

## Overview

This project is a responsive portfolio website built with HTML, CSS, and JavaScript. It highlights professional skills, experience, projects, and contact information in an interactive layout.

## Key Features

- Responsive single-page layout with multiple content sections
- Sidebar profile card with contact details and social links
- Navigation tabs for About, Resume, Portfolio, Projects, and Contact
- Services summary, skills progress bars, and client section
- Project and blog timeline sections for portfolio highlights
- Interactive mobile sidebar toggle
- Portfolio filter dropdown and category buttons
- Contact form with validation; Formspree endpoint used for form submission
- Google Fonts integration and Ionicons icon support

## Project Structure

- `index.html` — main portfolio HTML file
- `assets/css/style.css` — custom styling and responsive layout
- `assets/js/script.js` — interactivity for navigation, sidebar, filters, and form validation
- `assets/images/` — image assets used in the portfolio

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts (Poppins)
- Ionicons
- Formspree for contact form submission

## Usage

1. Clone or download the repository.
2. Open `index.html` in a web browser.


## Notes

- The page uses external CDN resources for icons and fonts.
- The contact form action points to a Formspree endpoint and requires Formspree configuration if customized.
